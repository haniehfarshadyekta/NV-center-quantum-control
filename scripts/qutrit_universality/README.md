
# Qutrit-Gate Universality

## Overview

This directory contains an exact symbolic implementation supporting the Lie-algebraic part of a universality analysis for a pair of qutrit gates.

The gate set consists of the qutrit Fourier transform, $H_3$, and a diagonal qutrit gate, $T_3$. The central question is whether finite products of these gates can approximate arbitrary unitary transformations on a three-dimensional Hilbert space, up to a global phase.

The analysis combines:

- Spectral analysis of auxiliary unitary matrices.
- Topological density arguments involving powers of unitary matrices.
- Irrationality of an eigenvalue phase.
- Construction of generators of $\mathfrak{su}(3)$.
- Exact symbolic verification of linear independence using SymPy.

The Python implementation focuses on the exact algebraic verification of the Lie-algebra generators.

## Qutrit Gate Definitions

The qutrit Fourier transform is defined as

```math
H_3=\frac{1}{\sqrt{3}}
\begin{pmatrix}
1&1&1\\
1&\omega_3&\omega_3^2\\
1&\omega_3^2&\omega_3
\end{pmatrix},
\qquad
\omega_3=e^{2\pi i/3}.
```

The diagonal gate is

```math
T_3=
\begin{pmatrix}
1&0&0\\
0&\xi^8&0\\
0&0&\xi
\end{pmatrix},
\qquad
\xi=e^{2\pi i/9}.
```

Here, $\omega_3$ is a primitive third root of unity and $\xi$ is a primitive ninth root of unity.

## Auxiliary Unitary Matrices

To investigate the group generated by the two gates, we construct two auxiliary matrices:

```math
R=H_3T_3H_3^\dagger T_3^\dagger,
```

```math
S=H_3T_3^\dagger H_3^\dagger T_3.
```

Both matrices are unitary and have determinant one.

For the first matrix, the trace can be expressed as

```math
\mathrm{Tr}(R)
=
\frac{1}{3}
(1+\xi+\xi^8)
(1+\xi^{-1}+\xi^{-8}).
```

Using $\xi+\xi^{-1}=2\cos(2\pi/9)$, this becomes

```math
\mathrm{Tr}(R)
=
\frac{1}{3}
\left(1+2\cos\frac{2\pi}{9}\right)^2.
```

The trace is real. Consequently, the eigenvalues of $R$ can be written as

```math
\operatorname{spec}(R)
=
\{1,e^{i\theta},e^{-i\theta}\}.
```

The angle $\theta$ is determined by the trace relation

```math
1+2\cos\theta
=
\frac{1}{3}
\left(1+2\cos\frac{2\pi}{9}\right)^2.
```

The matrix $S$ has the same trace and determinant, so it has the same eigenvalue structure.

## Irrationality of the Eigenvalue Phase

A central step in the density argument is establishing that $\theta/(2\pi)$ is irrational.

Define

```math
x=\xi+\xi^{-1}.
```

Since $\xi^9=1$ and $\xi^3\neq1$, we have

```math
\xi^6+\xi^3+1=0.
```

Dividing by $\xi^3$ gives

```math
\xi^3+\xi^{-3}+1=0.
```

Expanding $x^3$ and using this identity yields

```math
x^3-3x+1=0.
```

Now define

```math
y=\frac{(1+x)^2}{3}-1.
```

Using the relation satisfied by $x$, we obtain

```math
3y^3-3y-1=0.
```

The trace relation gives $y=2\cos\theta$.

The rational root theorem shows that the only possible rational roots of this cubic are

```math
y\in
\left\{
1,-1,\frac{1}{3},-\frac{1}{3}
\right\}.
```

None of these values satisfies the polynomial. Therefore, $y$ is irrational.

Furthermore, the polynomial $3y^3-3y-1$ is irreducible over $\mathbb{Q}$ and its monic normalization has a non-integer coefficient. Thus, $y$ is not an algebraic integer.

If $e^{i\theta}$ were a root of unity, then both $e^{i\theta}$ and $e^{-i\theta}$ would be algebraic integers. Their sum,

```math
e^{i\theta}+e^{-i\theta}=2\cos\theta=y,
```

would also have to be an algebraic integer, which is a contradiction.

Consequently,

```math
\boxed{\frac{\theta}{2\pi}\notin\mathbb{Q}.}
```

## Topological Density of Powers

Since $\theta/(2\pi)$ is irrational, the powers of $e^{i\theta}$ are dense on the unit circle.

Using the spectral decomposition of $R$, its powers can approximate matrices of the form

```math
V
\begin{pmatrix}
1&0&0\\
0&e^{i\phi}&0\\
0&0&e^{-i\phi}
\end{pmatrix}
V^\dagger,
\qquad \phi\in\mathbb{R}.
```

The same reasoning applies to $S$, with its own eigenbasis.

Thus, powers of $R$ and $S$ generate two continuous one-parameter subgroups in the closure of the group they generate.

## Lie-Algebra Generators

We introduce the anti-Hermitian generators

```math
A=
\frac{\theta}{2\sin\theta}
(R-R^\dagger),
```

```math
B=
\frac{\theta}{2\sin\theta}
(S-S^\dagger).
```

These satisfy

```math
A^\dagger=-A,
\qquad
B^\dagger=-B,
```

and, because the traces of $R$ and $S$ are real,

```math
\mathrm{Tr}(A)=\mathrm{Tr}(B)=0.
```

Therefore,

```math
A,B\in\mathfrak{su}(3).
```

The next step is to determine whether these generators and their nested commutators span the entire eight-dimensional Lie algebra $\mathfrak{su}(3)$.

## Exact Symbolic Verification

The script `lie_algebra_closure.py` performs this calculation using SymPy.

### Cyclotomic reduction

All expressions are represented in terms of the ninth root of unity $\xi$.

The relation

```math
\xi^6+\xi^3+1=0
```

is used to reduce polynomial expressions exactly.

In the implementation, the polynomial is defined as

```python
Phi = z**6 + z**3 + 1
```

The function `reduce_exact` expands polynomial expressions over the rational numbers and reduces them modulo this cyclotomic relation.

The function `reduce_matrix` applies this operation to every entry of a matrix.

Complex conjugation is handled exactly using

```math
\overline{\xi}=\xi^8.
```

This avoids floating-point approximations in the symbolic calculations.

### Construction of the Lie-algebra basis

The matrices $H_3$, $T_3$, their adjoints, and the auxiliary matrices $R$ and $S$ are constructed symbolically.

The implementation then defines the anti-Hermitian parts

```math
A_{\mathrm{code}}=R-R^\dagger,
\qquad
B_{\mathrm{code}}=S-S^\dagger.
```

These differ from the analytically normalized generators only by a common nonzero scalar factor, which does not affect the generated Lie algebra or the linear-independence test.

The commutator is implemented as

```python
def comm(A, B):
    return reduce_matrix(A*B - B*A)
```

Starting with $A_{\mathrm{code}}$ and $B_{\mathrm{code}}$, the script constructs eight matrices:

```math
\begin{aligned}
L_1&=A,\\
L_2&=B,\\
L_3&=[A,B],\\
L_4&=[B,L_3],\\
L_5&=[L_3,A],\\
L_6&=[L_3,L_4],\\
L_7&=[L_4,A],\\
L_8&=[L_4,B].
\end{aligned}
```

All eight matrices are traceless and belong to $\mathfrak{su}(3)$.

### Exact linear-independence test

Each $3\times3$ matrix is vectorized using its first eight row-major entries.

The final diagonal entry is omitted because the matrices are traceless and this entry is determined by the other two diagonal entries.

The resulting vectors are assembled as columns of an $8\times8$ matrix:

```math
M=
\begin{pmatrix}
|&|&&|\\
\operatorname{vec}(L_1)&
\operatorname{vec}(L_2)&
\cdots&
\operatorname{vec}(L_8)\\
|&|&&|
\end{pmatrix}.
```

The determinant is evaluated exactly using SymPy.

A nonzero determinant establishes that the eight matrices are linearly independent. Since $\dim\mathfrak{su}(3)=8$, they form a basis of $\mathfrak{su}(3)$.

Therefore, the Lie algebra generated by $A$ and $B$ is the full $\mathfrak{su}(3)$.

## Universality Result

Let

```math
G=\langle R,S\rangle
```

denote the group generated by finite products of $R$, $S$, and their inverses.

The density of the powers of $R$ and $S$, together with the generation of the full Lie algebra $\mathfrak{su}(3)$, establishes that $G$ is dense in $\mathrm{SU}(3)$.

In particular, for every $U\in\mathrm{SU}(3)$ and every $\varepsilon>0$, there exists $W\in G$ such that

```math
\|U-W\|<\varepsilon.
```

Since $R$ and $S$ are constructed from $H_3$, $T_3$, and their adjoints, the original gate set inherits this universality up to a global phase.

To express the Fourier gate as an element of $\mathrm{SU}(3)$, define

```math
\widetilde H_3=e^{i\pi/6}H_3.
```

Since $\det(H_3)=-i$, this phase adjustment gives $\det(\widetilde H_3)=1$. Also, $\det(T_3)=1$.

The resulting universality statement is

```math
\boxed{
\overline{\langle\widetilde H_3,T_3\rangle}
=
\mathrm{SU}(3).
}
```

## Script

`lie_algebra_closure.py`

The script performs the exact symbolic construction of the auxiliary matrices, their anti-Hermitian parts, and the eight nested-commutator matrices.

It then assembles the corresponding $8\times8$ matrix and evaluates its determinant exactly.

The script prints:

- The exact symbolic determinant.
- Whether the determinant is identically zero.

A nonzero determinant verifies the linear independence required for the Lie-algebra generation argument.

The irrationality of the eigenvalue phase and the topological density argument are established analytically; they are not numerical calculations performed by the script.

## Run

From the repository root:

```bash
python scripts/qutrit_universality/lie_algebra_closure.py
```

## Scope

This implementation addresses the symbolic Lie-algebra verification associated with qutrit-gate universality.

It does not perform pulse optimization or simulate the physical implementation of the gates. The GRAPE-based implementations for the Fourier and diagonal qutrit gates are maintained separately in `scripts/grape/`.
