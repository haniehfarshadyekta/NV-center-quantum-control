# Research documentation

Keep code-documentation notes, descriptions of model assumptions, and validation instructions here. The full BSc manuscript and independent quantum-control textbook study manuscript are intentionally not included in this starter package. Review any proposed public release for supervisor permission, unpublished results, and third-party copyrighted content.

Suggested future additions:
- `model_assumptions.md`: Hamiltonian and units, control conditions, numerical tolerances.
- `reproducibility.md`: interpreter and dependency versions, random seeds, output logs.
- `validation.md`: analytical gradient checks and Lie-algebra dimension cross-checks.
